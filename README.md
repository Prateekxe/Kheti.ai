# **Plant Health Detection App 🌱**  

🚀 A **Flask-based web application** that utilizes **YOLOv6** for object detection and **plant health analysis**.  

---

## **🌟 Overview**  

The **Plant Health Detection App** allows users to **upload images of plants**, detect objects (such as diseases, pests, or nutrient deficiencies), and receive **detailed insights** on plant health. The app provides:  
✅ **Precautions** to prevent plant diseases  
✅ **Avoidance measures** to minimize risks  
✅ **Cures** for identified plant health issues  

---

## **🛠 Features**  

- 🌿 **Plant Disease Detection** – Upload images to detect plant-related issues.  
- 🖼️ **Image Processing & Bounding Boxes** – Displays detected objects with bounding boxes.  
- 📊 **Health Analysis Report** – Provides **detailed insights** on detected classes.  
- 📏 **On-the-Fly Image Resizing** – Optimizes image size for better performance.

## **⚙️ Installation Guide**  

### **🔹 Prerequisites**  

Before running the application, ensure you have:  
✅ **Python 3.7 or higher**  
✅ **Pip (Python package manager)**  
✅ **OpenCV (`cv2`)** for image processing  
✅ **YOLOv6 Model File (`best_ckpt.onnx`)** for object detection  

### **🔹 Clone the Repository**  

```bash
git clone https://github.com/yourusername/plant-health-detection-app.git
cd plant-health-detection-app
```

---

## **🚀 How to Run the Application**  

1️⃣ Install dependencies:  
```bash
pip install -r requirements.txt
```
2️⃣ Run the Flask app:  
```bash
python app.py
```
3️⃣ Open your browser and go to:  
```bash
http://127.0.0.1:5000
```
